#### Hoopla
- Hoopla v2 now refreshes records queued for reindexing from Hoopla, including metadata, entitlements and Flex availability. Records that are not in Aspen yet are added. ([DIS-2784](https://aspen-discovery.atlassian.net/browse/DIS-2784)) (*YL*)
    - Add a Hoopla Aspen Information page, add Records to Reindex to Hoopla Aspen Information.
    - Records to Reindex accepts Hoopla IDs, separated by new lines or commas.
    - Force Reindex on a Hoopla record now also refreshes the record from Hoopla.
