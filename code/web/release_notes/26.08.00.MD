### Search Updates
- Add new settings for configuring search types and sort options ([DIS-2622](https://aspen-discovery.atlassian.net/browse/DIS-2622)) (*KL*)
  - Requires admin permission "Administer All Search Settings"
  - Search Types can be disabled, enabled for basic & advanced searches, or enabled for advanced searches only
  - Sort Options can be enabled or disabled
  - If there is only one search type, it will not show on the search bar

- Administer All Search Settings - Controls if the user can search settings.
