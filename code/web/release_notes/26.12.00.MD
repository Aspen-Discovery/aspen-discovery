#### Web Builder
- Hero sliders now scale to fit the screen on phones and other small screens instead of using a fixed 600px height that cropped the slides. The slider's height now follows its aspect ratio, the previous and next arrows are now full-height panels down each side of the slider that are always visible, the pause button is always visible on touch screens, and the embed code on the hero slider's admin page uses the new sizing.
