#### Grouped Works
- When "Hide Indexed E-Content Series" is enabled, a series is now only hidden if it comes solely from OverDrive or Hoopla. Series that are also supplied by a MARC record in the grouped work (for example, from the ILS) are no longer hidden when an OverDrive or Hoopla title uses the same series name.
