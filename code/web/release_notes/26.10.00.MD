## Aspen Discovery Updates
### Bug Fixes and Code Maintenance
#### Administration
- Add the Last Check In Date and Last Check In Date Format settings to Sierra indexing profiles. ([DIS-2920](https://aspen-discovery.atlassian.net/browse/DIS-2920)) (*YL*)
- Fix property search in ILS Indexing Profiles so settings that do not apply to the active ILS are no longer displayed. Search results now show only matching settings and their relevant sections, hiding empty sections. ([DIS-2921](https://aspen-discovery.atlassian.net/browse/DIS-2921)) (*YL*)

#### Aspen API
- Update User API `getPatronProfile` to return `barcodeStyle` for the patron's home library. ([DIS-2889](https://aspen-discovery.atlassian.net/browse/DIS-2889)) (*KK*)

#### Code Maintenance
- Added a way to get a stored file's size through the storage abstraction layer, laying groundwork for future storage backend support. ([DIS-3008](https://aspen-discovery.atlassian.net/browse/DIS-3008)) (*LM*)
- Batch fix redundant code pattern across codebase, removing 309 redundancies from Aspen Discovery. ([DIS-2898](https://aspen-discovery.atlassian.net/browse/DIS-2898)) (*JW*)

#### Cover Images
- Internationalisation: fixed an issue where default book cover displayed the author and title with each word capitalised regardless of the casing obtained from the relevant marc records. ([DIS-2916](https://aspen-discovery.atlassian.net/browse/DIS-2916)) (*CZ*)
- Fixed generated placeholder covers rendering at the wrong size and retrying after a failed title lookup instead of permanently caching "Unknown Title". ([DIS-2927](https://aspen-discovery.atlassian.net/browse/DIS-2927)) (*LM*)

#### Events
- Event date covers now update when the event does. Previously, changing an event's title, date or branch left the old cover in place for two to four weeks. Now, running an event search will always show up to date event date covers. ([DIS-2970](https://aspen-discovery.atlassian.net/browse/DIS-2970)) (*CZ*)
- Whether an event shows as past is now based on its date rather than on how its cover was requested, which prevents inconsistencies. ([DIS-2970](https://aspen-discovery.atlassian.net/browse/DIS-2970)) (*CZ*)
- Date covers for past Aspen events saved to a list now show that event's own title and date rather than another event's. ([DIS-2970](https://aspen-discovery.atlassian.net/browse/DIS-2970)) (*CZ*)
- Date covers that are no longer in use are now removed by the cover cleanup instead of being left in place for up to four weeks. This is important as we generate new event date covers on relevant event details changes. ([DIS-2970](https://aspen-discovery.atlassian.net/browse/DIS-2970)) (*CZ*)

#### Indexing
- Update GroupedWorksIndexer to use try-with-resources blocks ensuring proper resource cleanup. ([DIS-2913](https://aspen-discovery.atlassian.net/browse/DIS-2913)) (*JW*)

#### Interface Updates and Usability
- Added remembering user consent when logging into Aspen Discovery with an OAuth Client so now users won't be asked to re-consent unless scope(s) of the client has changed. ([DIS-2960](https://aspen-discovery.atlassian.net/browse/DIS-2960)) (*KK*)

#### JavaScript Snippets

#### Koha ILS
- Fix expired Koha patron restrictions continuing to display the account as frozen. ([DIS-2992](https://aspen-discovery.atlassian.net/browse/DIS-2992)) (*LE*)

#### Languages and Translations
- Made the "Noon" and "Midnight" labels shown in library hours translatable. (DIS-2926) (*CZ*)
- Remaining hardcoded JS phrases have been modified to be translatable via the 'Translation Mode' module ([DIS-2979](https://aspen-discovery.atlassian.net/browse/DIS-2979)) (*LM*)

#### Reports and Statistics
- DIS-2789: Track Aspen usage statistics with atomic increments and add a unique key on daily rows so counts are no longer lost when requests are processed at the same time, and concurrent requests can no longer create duplicate rows for a single day. ([DIS-2789](https://aspen-discovery.atlassian.net/browse/DIS-2789)) (*KMH*)

#### Server Setup
- Upgrade the Docker image's base OS to Debian trixie, Java runtime to OpenJDK 25, and PHP to trixie's native 8.4 package. ([DIS-2894](https://aspen-discovery.atlassian.net/browse/DIS-2894)) (*LM*)

#### Side Loading
- When adding a new side load, if the new setting doesn't validate, the form that appears to let you try again no longer incorrectly displays the MARC Path and Record URL Component fields. ([DIS-2462](https://aspen-discovery.atlassian.net/browse/DIS-2462)) (*GMC*)

#### Sierra ILS
- Validate PINs during Sierra self registration using the configured PIN validation rules. ([DIS-2973](https://aspen-discovery.atlassian.net/browse/DIS-2973)) (*LE*)

#### Web Builder
- Fix an issue that prevents images from being uploaded through the WebBuilder Markdown editor. ([DIS-2950](https://aspen-discovery.atlassian.net/browse/DIS-2950)) (*YL*)
