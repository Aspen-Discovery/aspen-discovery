#### Omeka
- Add an Omeka module that indexes items from Omeka S and Omeka Classic servers through the Omeka REST API. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Add Omeka Settings to connect to a server and Omeka Scopes to select the item sets or collections to index for each library and location. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Display Omeka items as online eContent with a link to the item on the Omeka site. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Add an Omeka Indexing Log to review extractions. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
- Add a setting to group Omeka items that share a title, author, and format into one work. ([DIS-894](https://aspen-discovery.atlassian.net/browse/DIS-894)) (*JOM*)
