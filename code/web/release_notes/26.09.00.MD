## Aspen Discovery Updates
### New Features and Enhancements
#### Administration
- Add an early warning for invalid Regex so that other unsaved changes are not lost when attempting to save library settings ([DIS-2760](https://aspen-discovery.atlassian.net/browse/DIS-2760)) (*CZ*)
- Display selected libraries and locations within list of records for Placards, Web Builder (Basic Pages, Custom Pages, Grapes Pages, Custom Forms (count only), Quick Polls, Web Resources, Custom Web Resource Pages), and System Messages.  ([DIS-2849](https://aspen-discovery.atlassian.net/browse/DIS-2849)) (*MDN*)

#### Aspen API
- In System API, added `getAspenLiDAThemeInfo` to retrieve Aspen LiDA Theme information for a given theme id. ([DIS-2711](https://aspen-discovery.atlassian.net/browse/DIS-2711)) (*KK*)
- In System API, added `getAspenLiDAThemesByLocation` to retrieve Aspen LiDA Theme information (may be multiple) for a given library location. ([DIS-2711](https://aspen-discovery.atlassian.net/browse/DIS-2711)) (*KK*)

#### Aspen LiDA
- Add Aspen LiDA Themes to allow for more customization and control over accessibility, particularly with color contrast ratios. This also marks the deprecation of several Aspen LiDA-related items in Aspen Discovery's Themes: `logoApp`, `headerLogoApp`, `headerLogoAlignmentApp`, `headerLogoBackgroundColorApp`, and values set in Aspen LiDA Themes will take precedence over these old fields. Libraries with branded apps will see more options for customizing (matching previous customizability) than those without. ([DIS-2711](https://aspen-discovery.atlassian.net/browse/DIS-2711)) (*KK*)
