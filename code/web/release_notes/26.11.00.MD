#### Events
- Fix an issue where saving a recurring event after changing its repeat options recreated every date in the recurrence, including past dates, creating duplicate event instances. ([DIS-3014](https://aspen-discovery.atlassian.net/browse/DIS-3014)) (*YL*)
    - Past instances are now left untouched when a recurring event is edited.
    - Upcoming dates that are still scheduled are kept, dates removed from the schedule are deleted, and newly added dates are created.
    - Duplicate instances created before this fix are not removed automatically and need to be deleted manually.
- When adding a new event type, attendee categories from other event types are no longer loaded into the form. Previously, removing them from the new event type also deleted them from the original event types. ([DIS-3087](https://aspen-discovery.atlassian.net/browse/DIS-3087)) (*SY*)

##### Introduce database transactions
- Event registrations are now saved as a whole. If any part fails, nothing is kept, and the patron or member of staff is told the registration did not work instead of being shown a success message. Applies to patrons registering themselves and to staff registering patrons. ([DIS-2508](https://aspen-discovery.atlassian.net/browse/DIS-2508)) (*CZ*)
- Cancelling a registration is now all or nothing. A cancellation that fails part way through can no longer leave the registration in place without its attendee numbers. Applies to patrons cancelling their own registration and to staff cancelling on their behalf. ([DIS-2508](https://aspen-discovery.atlassian.net/browse/DIS-2508)) (*CZ*)
- Joining an event waiting list is now all or nothing, so a patron can no longer be queued for an event that is missing from their events list. ([DIS-2508](https://aspen-discovery.atlassian.net/browse/DIS-2508)) (*CZ*)
- Saving the event to linked viewer accounts' events lists is now included in the registration and waiting list transactions, so it succeeds or fails together with the registration. This prevents registrations from being created if the viewer account cannot manage them. ([DIS-2508](https://aspen-discovery.atlassian.net/browse/DIS-2508)) (*CZ*)
- Registration problems that were previously discarded are now written to the log with the underlying error. ([DIS-2508](https://aspen-discovery.atlassian.net/browse/DIS-2508)) (*CZ*)
