#### Aspen Progressive Web Application (PWA) 
-- Firebase settings now have their own admin page (Aspen Progressive Web Application(PWA) > Firebase Settings) and are assigned to libraries separately from the PWA settings. Existing values are copied automatically during the update, and roles that could administer PWA settings are given the new "Administer Firebase Settings" permission. Push notifications are now sent with the Firebase project that issued each device's token, so scheduled notifications reach patrons from every library, not only the default one. ([DIS-3165](https://aspen-discovery.atlassian.net/browse/DIS-3165)) (*IT*)
-- Aspen PWA settings now have an Icon field for a 512x512 PNG, which is used for the app icon instead of the theme's Aspen LiDA & PWA logo. If no icon is uploaded, the theme logo is still used. ([DIS-3165](https://aspen-discovery.atlassian.net/browse/DIS-3165)) (*IT*)
-- Remove the unused Slug field from Aspen PWA settings. ([DIS-3165](https://aspen-discovery.atlassian.net/browse/DIS-3165)) (*IT*)
