### NYT List Updates
- Added a “Run Full Update” option to ignore the last-modified date of NYT lists and allow them to be fully updated. 
- Added an “Enable Extensive Logging” option that will add more notes and errors to the NYT Update Log when enabled.
- Implemented a Greenhouse section and button to force the NYT Updater to run. 
- When “Run Full Update” is enabled, the NYT List Updater will automatically run a couple of minutes thereafter; it will not run the updater if one is already running. 
- Updates may be halted in the Greenhouse and will successfully stop at a safe point (e.g., after a list has been fully processed). 
- Developer documentation now recommends sleeping 12 seconds between calls instead of the previous 6 seconds (https://developer.nytimes.com/faq). Thus, the updater will sleep for 13 seconds between calls. 
- Updated NYT API calls to use v3 (https://developer.nytimes.com/docs/books-product/1/overview), where the two relevant calls are `lists/names.json` for general list data and `lists/current/{list_name}.json` for books data.
